 Aperto alla fine del 2025, il ristorante Sextantio – Cucina porta la firma di Dino Como , per quindici anni al fianco di Niko Romito al Reale di Castel di Sangro. Un progetto voluto dall’imprenditore Daniele Kihlgren, ideatore dell’albergo diffuso Sextantio, scomparso lo scorso 8 ottobre, che ha affidato allo chef il compito di sviluppare una cucina legata alla storia e alle tradizioni del territorio. Il risultato è un ristorante che propone due percorsi degustazione, uno dedicato alla memoria gastronomica locale e l’altro alla sperimentazione. Nella guida Ristoranti d’Italia 2027 del Gambero Rosso ha ottenuto il premio speciale Partesa La Novità dell’Anno . 
 
 Sextantio – Cucina 
 Aperto alla fine del 2025, il ristorante porta la firma di Dino Como, per quindici anni al fianco di Niko Romito (il Reale di Castel di Sangro quest’anno ha conquistato il vertice della Guida Ristoranti d’Italia 2027 con 99/100). Oggi Como è protagonista di un percorso personale, tanto rigoroso quanto audace. A volere fortemente questo progetto gastronomico è stato Daniele Kihlgren , l’imprenditore visionario, ideatore dell’ albergo diffuso Sextantio , scomparso lo scorso 8 ottobre . Era convinto che, per salvare un luogo, fosse necessario prima di tutto rispettarlo, lasciandolo il più possibile com’era. Non abbellirlo, non piegarlo ai canoni dell’ospitalità contemporanea, non aggiungere ciò che mancava. Semmai togliere, per restituire valore a ciò che già esisteva. Una filosofia che ha guidato il recupero di Santo Stefano di Sessanio e che oggi trova una nuova espressione nella cucina. È stato proprio Kihlgren a chiamare Dino Como, riconoscendo in lui la sensibilità e il coraggio necessari per dare forma a un progetto gastronomico coerente con l’identità del luogo, anche grazie alla complicità di Nunzia Taraschi , antropologa e CEO di Sextantio. 
 
 Due menu degustazione 
 «Territorio, memoria, ricerca», così recita la copertina in ruvida carta avorio del menu. Il territorio in effetti si ritrova negli ingredienti, perlopiù autoprodotti. La memoria, in ogni angolo del locale, a partire dal camino in tufo, carico di fascino e simbologia. Mentre la ricerca sta nel difficile equilibrio tra la tutela dell’identità regionale e una cucina d’autore dinamica e alquanto personale. Due i menu degustazione: Radici è il percorso più filologico, che ricostruisce il patrimonio gastronomico delle comunità locali e della pastorizia, legata anche alla Baronia di Carapelle. Ma è soprattutto nel menu Evoluzione che emerge la personalità di Como. Tra estrazioni, fermentazioni e riduzioni della materia prima, ne esplora potenzialità aromatiche, sfumature tattili ed eccessi chemestetici. 
 Lattuga vaniglia e limone del menu Evoluzione 
 Un lavoro iniziato con il maestro Niko Romito, ma oggi già evoluto nel proprio manifesto culinario di amari dirompenti, texture nitide e astringenze disorientanti. Qui lo chef eleva il registro agro-pastorale a repertorio d’alta scuola: la lattuga diventa un dessert con vaniglia e limone fermentato di sofisticata opulenza, le lenticchie di Santo Stefano con cotica e alloro invece sono servite asciutte e sgranate, in contrapposizione alla fluidità delle zuppe locali. Esperienza per qualcuno poco ortodossa. Eppure, da consigliare, anche grazie al servizio premuroso e a una selezione enologica originale. 
 Santo Stefano di Sessanio (AQ) – via Nazario Sauro – 0862 899116 – www.sextantio.it

 // Osservatore per intercettare le animazioni dei widget
 function observeWidgets() {
 const widgets = document.querySelectorAll('.MENU_Premium .elementor-widget.animenu');
 widgets.forEach(widget => {
 if (widget.dataset.animated) return; // Evita duplicazioni
 widget.dataset.animated = true;
 
 const ul = widget.querySelector('ul');
 if (!ul) return;
 
 const listItems = ul.querySelectorAll('li');
 if (listItems.length === 0) return;
 
 // Rimuove l'animazione dal widget
 widget.style.animation = 'none';
 
 listItems.forEach((li, index) => {
 // Ritardo di 15ms tra un elemento e l'altro
 const delay = 15 + index * 15; 
 let animationDuration = '0.3s';
 // Le animazioni dei primi due saranno più lente
 if (index === 0 || index === 1) {
 animationDuration = '0.4s';
 }
 li.style.opacity = '0';
 li.style.animation = `fadeIn ${animationDuration} ease-in-out ${delay}ms forwards`;
 });
 });
 }
 
 // Osservatore per nuovi widget caricati dinamicamente
 const observer = new MutationObserver(observeWidgets);
 observer.observe(document.body, { childList: true, subtree: true });
 
 // Esegue la funzione all'inizio
 observeWidgets();
});

// Definizione dell'animazione
const style = document.createElement('style');
style.innerHTML = `
@keyframes fadeIn {
 from { opacity: 0; transform: translateY(10px); }
 to { opacity: 1; transform: translateY(0); }
}`;
document.head.appendChild(style);
