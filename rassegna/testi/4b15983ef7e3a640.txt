 Salvatore Tassa va dritto alle origini del sapore, senza riserve né mediazioni. È un fuoriclasse della ristorazione italiana. E se dovessimo chiederci in quale direzione dovrebbe andare la nostra cucina, la risposta sarebbe una sola: verso Acuto. 
 La cucina di Salvatore Tassa nella trattoria di Acuto 
 Tra la Trattoria Nú, che anche quest’anno conferma i Tre Gamberi nella nostra guida Ristoranti d’Italia, e il ristorante del piano di sopra cambia la cornice, ma non lo stile del quadro. E lo stile è quello definito dalla filosofia gastronomica di Salvatore Tassa, il cuoco visionario che insegnava nei corsi di antropologia culturale di Massimo Canevacci alla Sapienza. La cucina di Tassa è la concretizzazione del concetto di Retro-Innovazione nel cibo, riesumato dalle teorie economiche di Schumpeter: avanguardia e tecniche innovative con i piedi saldamente piantati nel terreno della cultura tradizionale territoriale. 
 
 Cosa si mangia 
 Entrando in Trattoria, tutta legno e con il capriccio dei quadri-specchio liberty alle pareti, accolti dalla famiglia Tassa, dimenticherete lezioni e cattedre per lasciare spazio al gusto e alle sorprendenti sensazioni di una tartare di pomodoro e gelsi, o della misticanza selvatica con barbabietola al profumo di limone e liquirizia. Se la minestra fredda di erbe spontanee in ghiaccio è chimica empirica, si va a briglie sciolte attraverso il gusto nei raviolini di mortadella e parmigiano in salsa di ciliegia . Studio, tecnica e selezione delle materie prime nell’agnello cotto nel fieno maggengo in forno a legna o nella salsiccia di carni miste, maiale, angus e capra servita insieme all’agnello, nel piatto con fagiolini alla menta. Si chiude con l’interpretazione del cannolo o una crema di latte di capra al timo. 
 Manzo cotto su una foglia di fico 
 Lo stile di presentazione dei piatti è, volutamente, evocativo di una locanda di altri tempi, come il bancone rustico all’entrata, interamente ricostruito dal figlio di Salvatore, Giovanni. Se il clima lo consente, si può pranzare all’aperto con vista sulla vallata, serviti in modo professionale, pure se poi qui ci si rilassa e si parla tanto: di cibo ma anche di vita, grazie ai frequenti interventi in sala dello chef. Un maestro della cucina italiana diceva «io sono un cuoco, non vendo vino». Tassa ha lo stesso pensiero, ma non trascura l’importanza di un buon abbinamento tra cibo e vino. Inutile parlare di menu, perché comanda la stagione, ma sarete pienamente soddisfatti, anche del conto. 
 Salvatore Tassa sarà inoltre tra i protagonisti della cena delle Tre Forchette 2027 , in programma il 26 ottobre alla Nuvola di Roma , dove porterà il suo Antipasto all’italiana: coppa aromatizzata con frutta, mela cotogna e agrumi, servita con broccoletti e cicoria accompagnati da un chutney di mandarino bruciato. Più ristorazione italiana di così… 
 Acuto (FR) – via Prenestina, 27 – 0775 56049

document.addEventListener('DOMContentLoaded', function () {
 // Osservatore per intercettare le animazioni dei widget
 function observeWidgets() {
 const widgets = document.querySelectorAll('.MENU_Premium .elementor-widget.animenu');
 widgets.forEach(widget => {
 if (widget.dataset.animated) return; // Evita duplicazioni
 widget.dataset.animated = true;
 
 const ul = widget.querySelector('ul');
 if (!ul) return;
 
 const listItems = ul.querySelectorAll('li');
 if (listItems.length === 0) return;
 
 // Rimuove l'animazione dal widget
 widget.style.animation = 'none';
 
 listItems.forEach((li, index) => {
 // Ritardo di 15ms tra un elemento e l'altro
 const delay = 15 + index * 15; 
 let animationDuration = '0.3s';
 // Le animazioni dei primi due saranno più lente
 if (index === 0 || index === 1) {
 animationDuration = '0.4s';
 }
 li.style.opacity = '0';
 li.style.animation = `fadeIn ${animationDuration} ease-in-out ${delay}ms forwards`;
 });
 });
 }
 
 // Osservatore per nuovi widget caricati dinamicamente
 const observer = new MutationObserver(observeWidgets);
 observer.observe(document.body, { childList: true, subtree: true });
 
 // Esegue la funzione all'inizio
 observeWidgets();
});

// Definizione dell'animazione
const style = document.createElement('style');
style.innerHTML = `
@keyframes fadeIn {
 from { opacity: 0; transform: translateY(10px); }
 to { opacity: 1; transform: translateY(0); }
}`;
document.head.appendChild(style);
